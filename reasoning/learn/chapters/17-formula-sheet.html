In one line: every rule and "Memorise this" box from the guide on one page, for the night before the exam.

Exam facts (official PFRDA notification): Phase I on 15 Oct 2026. Reasoning 30 questions, 25 marks, so 0.8333 per question (25 ÷ 30). Official wording: negative marking is ¼ of the marks assigned. This guide uses a flat −0.25 per wrong answer as you directed (check your call letter). Break-even chance about 23%. Paper 1 is 90 questions in one 60-minute timer, shared with English, Reasoning and General Awareness. Separate cut-off per paper plus an aggregate.

01Start Here: Reasoning game plan

Rules

Right = +0.8333. Wrong = −0.25. Skipped = 0.
Break-even chance = the chance of being right at which a guess gains nothing and loses nothing on average. If p is your chance of being right: average gain p × 0.8333 equals average loss (1 − p) × 0.25 when p = 0.25 ÷ (0.8333 + 0.25) = 0.25 ÷ 1.0833 = 0.2308 = 23.1%, about 23%.
Guess only if your chance of being right is above about 23%. Under the official-wording reading (0.2083) the break-even is 0.2083 ÷ (0.8333 + 0.2083) = 20%, so 23% is safe under both.

Memorise


1. Reasoning: 30 Q, 25 marks, 0.8333 each.
2. Wrong = −0.25 here (official: 1/4 of marks, call letter settles).
3. Guess only above about 23%.
4. One 60-minute timer for all 90 Q.
5. Easy topics first, long puzzles last.

02Inequalities (direct and coded)

Rules

Same direction chain: the ends are related. Direction change: the ends are NOT related (not definite).
Strict wins: if any link is > (or <), the ends are strict. If all links are ≥ (or all ≤), the ends are ≥ (or ≤). If all links are =, the ends are =.
= links are invisible: they take on the neighbour's relation.
Sign-combine table (walking left to right): > then > = >; > then ≥ = >; ≥ then ≥ = ≥; = then X = X.
A conclusion follows only if it is true in every case.
Either-or: neither conclusion follows alone, both talk about the same two letters, and in every case at least one of them is true.
Complementary pairs (two claims on the same two letters where at least one is always true; checked, with no statement linking the two letters): < with ≥, > with ≤, and ≤ with ≥.
NOT either-or when the letters are unlinked: > with < (both fail when equal), > with = (both fail when A < B), > with ≥ (both fail when A < B).
Linked case: if the statements give A ≥ B, then I. A > B and II. A = B is either-or (≥ leaves only those two cases). Always test "can both be false in some case that fits the statements?"
Decode symbol by symbol: A @ B uses the key sign between A and B.
A coded statement with three letters, like P @ Q # R, is a chain: P > Q ≥ R if @ is > and # is ≥.
After decoding, all the rules of Lessons 1 and 2 apply unchanged.

Memorise (lesson 1)


1. Same direction: walk. Direction change: no relation.
2. One strict link makes the ends strict.
3. All ≥ gives only ≥.
4. = links are invisible.
5. Definitely true means true in every case.

Memorise (lesson 2)


1. Walk each conclusion alone first.
2. Either-or: neither follows, same two letters, one always true.
3. Pairs: < with ≥; > with ≤; ≤ with ≥.
4. Unlinked > with <, > with =, > with ≥: not either-or. (Given A ≥ B, > with = IS either-or.)

Memorise (lesson 3)


1. Symbols mean what the key says, nothing else.
2. Decode every symbol, keep the letter order.
3. Then flip, line up, walk the chain.
4. Either-or only at the end.
5. The key changes every question.

03Syllogism

Rules

All A are B ⇒ Some A are B, Some B are A. (NOT All B are A.)
No A is B ⇒ No B is A, Some A are not B, Some B are not A.
Some A are B ⇒ Some B are A. Nothing else.
Some A are not B ⇒ nothing new. (Some B are not A does NOT follow.)
Some then All gives Some. All then Some gives nothing.
Some-Some, No-No: nothing definite about A and C. Some-not first in this table: nothing.
Cannot line B up like the table? Three verified extra shapes: All B are A + All B are C ⇒ Some A are C. All A are B + Some C are not B ⇒ Some C are not A. Some B are not A + All B are C ⇒ Some C are not A. Anything else: draw it or use the lab below.
Possibility fails ⇔ the opposite (All↔Some-not, No↔Some) definitely follows.
Either-or: no conclusion definite alone, and one of the two is true in every picture. Works for the pairs Some/No, All/Some-not, Some/Some-not.
Only a few A are B = Some A are B + Some A are not B.

Memorise (lesson 1)


1. Some = at least one, maybe all.
2. Definite = true in EVERY legal picture.
3. No and Some swap freely.
4. All A are B gives Some B are A, never All B are A.
5. Some-not never swaps.

Memorise (lesson 2)


1. Test = can ONE legal picture break it?
2. Some-Some: nothing. No-No: nothing.
3. Some then All: Some.
4. All then Some: nothing.
5. No after All: No. No before All: Some-not.

Memorise (lesson 3)


1. Definite = every picture. Possible = one picture.
2. Possibility fails only if the opposite follows.
3. Either-or: neither alone, but one of them in every picture.
4. All/No: both can be false. Not either-or.
5. Only a few A are B = Some A are B + Some A are not B.

04Coding-Decoding

Rules

Position value: A = 1 ... Z = 26. Anchors: E 5, J 10, O 15, T 20, Y 25.
Shift +k: new position = old + k; if above 26, subtract 26. Shift −k: new = old − k; if below 1, add 26.
Decode a shift +k by applying −k (the opposite move).
A coding rule must send different letters to different letters, otherwise nobody could decode it (one-to-one).
Opposite letter: position p ↔ 27 − p. A↔Z, B↔Y, ..., M↔N.
Opposite twice = original letter (it is its own undo).
Reverse alphabet ≠ reverse word. Do exactly what the question says, in order.
Word substitution: common word → common code word (assuming one word, one code word).
Read the test first, decide the branch, then apply only that branch.
Chain: result of step 1 is the input of step 2. Do not swap the steps.
Test the original word unless told to test something else.
+k then opposite = opposite then −k (derived).

Memorise (lesson 1)


1. A = 1 ... Z = 26; anchors E5 J10 O15 T20 Y25.
2. Shift +k forward, −k backward; Z wraps to A.
3. Decode = reverse the move.
4. Test the rule on at least TWO letters.
5. Word value = sum of positions.

Memorise (lesson 2)


1. Opposite letter: p ↔ 27 − p.
2. AZ BY CX DW EV FU GT HS IR JQ KP LO MN.
3. Reverse the alphabet ≠ reverse the word.
4. Opposite twice = start again.
5. Substitution: common word, common code.

Memorise (lesson 3)


1. Test the ORIGINAL word, pick ONE branch.
2. Chain = step 1 on every letter, then step 2.
3. Order matters: A with +2 then opposite = X; opposite then +2 = B.
4. Write rows under the word.
5. Test the first letter through all steps to eliminate options.

05Blood Relations

Rules

Four moves: parent, child, sibling, spouse. Every relation name is a chain of them.
Uncle/aunt = parent’s sibling. Nephew/niece = sibling’s child. Cousin = child of a parent’s sibling. Grandparent = parent of a parent.
In-law = by marriage: spouse’s parent, child’s spouse, spouse’s sibling, sibling’s spouse, spouse’s sibling’s spouse.
Write the walk from the speaker. One phrase = one step.
Up = parent, down = child, sideways = sibling or spouse. Net generation = ups − downs.
“Only” re-uses a person already on the walk; no “only” means a new person.
Collapse: father’s wife = mother. Mother’s husband = father. Wife’s husband = the man himself.
Key used here: + mother, − father, × brother, ÷ sister.
A [symbol] B means: A is the [mother, father, brother or sister] of B.
First person’s relation to the LAST: start at the last person and apply the relations from the right-most pair back to the left.
Last person’s relation to the first: gender missing, so check whether the options force one.

Memorise (lesson 1)


1. Four moves: parent, child, sibling, spouse.
2. Uncle/aunt = parent’s sibling. Nephew/niece = sibling’s child.
3. Cousin = child of a parent’s sibling (no gender given).
4. Count up (+1) and down (−1) before naming.
5. In-law = by marriage: spouse’s side or your sibling’s spouse.

Memorise (lesson 2)


1. Start at the speaker; one phrase = one step.
2. Up = parent, down = child, sideways = sibling/spouse.
3. “Only” = no new person (a man’s father’s only son is himself).
4. Father’s wife = mother; mother’s husband = father.
5. Count generations, then side, then gender.

Memorise (lesson 3)


1. Read the key first; it changes every question.
2. “A symbol B” = A is the [word] of B (left person).
3. Walk from the LAST person, right to left.
4. Symbols give the left person’s gender, never the last’s.
5. Last to first often = “cannot be determined”.

06Direction and Distance

Rules

Order clockwise: N → E → S → W → N (90° each). Eight-point compass: add NE, SE, SW, NW (45° between).
Right turn = clockwise = +1 step of 90°. Left turn = anticlockwise = −1 step.
Net turns = (rights) − (lefts). If the net is negative, add 4 until it is 0 to 4 (so −1 counts as 3, −2 as 2). Net 1 = right, net 2 = about-turn, net 3 = left, net 0 or 4 = same heading.
Angles: heading in degrees clockwise from North (N 0°, E 90°, S 180°, W 270°). Add for a right turn, subtract for left, then wrap around 360°.
Position = (East, North). E: x + · W: x − · N: y + · S: y −.
Straight-line distance = √(x² + y²) (Pythagoras: a² + b² = c², c = hypotenuse, the side opposite the right angle).
Distance walked = sum of all legs. Straight-line ≤ walked, equal only if the whole path is a straight line.
Direction of end from start: by signs of x and y (both non-zero = a corner name such as North-East). Start from end = flip both signs.
Convention in this book: when both x and y are non-zero we use the corner name (North-East) even if the angle is not exactly 45°.
Shadow points directly away from the Sun.
Convention: sunrise Sun = East, so shadow = West. Sunset Sun = West, so shadow = East.
Facing N: R = E, L = W · Facing S: R = W, L = E · Facing E: R = S, L = N · Facing W: R = N, L = S.
Two travellers from one point: opposite directions → add · same direction → subtract · at right angles → √(a² + b²).

Memorise (lesson 1)


1. Compass runs clockwise: N, E, S, W.
2. Right = +1 step, left = −1 step.
3. Net 2 = about-turn.
4. Right and left belong to the person, so start from where he faces.
5. 45° points sit between the main four.

Memorise (lesson 2)


1. Start (0,0); E/W change x, N/S change y.
2. Straight line = √(x² + y²).
3. Walked = add all legs.
4. Triples: 3-4-5, 5-12-13, 8-15-17, 7-24-25.
5. Start from end: flip both signs.

Memorise (lesson 3)


1. Shadow points away from the Sun.
2. Morning shadow West, evening shadow East.
3. Facing N: R=E, L=W. Facing S: R=W, L=E. Facing E: R=S, L=N. Facing W: R=N, L=S.
4. Opposite add, same subtract, right angle Pythagoras.
5. Read the question: gap, walked, or direction?

07Order, Ranking, Alphanumeric series

Rules

Total = rank from left + rank from right − 1
Rank from the other end = Total − rank + 1
Between two people = |rank of one − rank of the other| − 1, with both ranks counted from the SAME end. (The bars | | mean "drop any minus sign": the gap between 8 and 19 is 11 either way round.)
Different people, one rank from the left (a) and one from the right (b). "Overlap" means the two counts run past each other, so the person counted from the left stands further right than the one counted from the right. If a + b ≤ Total then between = Total − a − b; if a + b > Total + 1 (the ranks overlap) then between = a + b − Total − 2. If a + b = Total + 1 they are the same person.
Swap: after two people swap, each sits in the other's old place. Translate the new rank into the old place of the other person.
m-th to the right of the n-th from the left = position n + m from the left
m-th to the left of the n-th from the left = position n − m from the left
n-th from the right = position (total − n + 1) from the left
Elements strictly between positions i and j = j − i − 1
Rank from bottom = Total − rank from top + 1
Alphabet: place from left + place from right = 27
Letters between two letters = (bigger place − smaller place) − 1
Two clues, "exactly k between": try both orders (B right of A and B left of A). Each can give a different total.

Memorise (lesson 1)


1. Total = left + right − 1.
2. Other end = total − rank + 1.
3. Between = gap of ranks − 1 (same end).
4. Ranks add to more than total: between = a + b − total − 2.
5. Swap: A takes B's old place.

Memorise (lesson 2)


1. Number the series first.
2. m to the right of n: position n + m.
3. n-th from the right: total − n + 1 from the left.
4. Between i and j: j − i − 1.
5. Last element has no "followed by".

Memorise (lesson 3)


1. Bottom rank = total − top rank + 1.
2. Alphabet: left place + right place = 27.
3. Anchors E J O T Y = 5 10 15 20 25.
4. Between = place gap − 1.
5. "Exactly k between": try both orders.

08Input-Output (machine)

Rules

Sort the target list ONCE on rough paper. Step k then only touches slot k.
Shift rule: pull the item out, insert it in slot k, keep the other items in their old order.
Stop count: n items need at most n − 1 steps (the last item settles itself). The machine stops after the last step that changes the line.
Odd step = word to the left. Even step = number to the right (when words go first).
Words: dictionary order. Numbers: largest first, each new one beside the last.
Middle items keep their input order.
A rule is right only if it reproduces EVERY given line.
Step I alone can fit shift AND swap. Use Step II.
Word-length order: shortest word first; all lengths must differ for a clear answer.

Memorise (lesson 1)


1. Sort the target list once.
2. Step k pulls the k-th item into slot k.
3. Other items keep their order (shift).
4. After step k: first k sorted + the rest in original order.
5. At most n − 1 steps.

Memorise (lesson 2)


1. Split into words and numbers; sort each.
2. Alternate: word step, number step.
3. Words fill from the left, numbers from the right.
4. Second number goes beside the first.
5. Middle keeps input order.

Memorise (lesson 3)


1. Compare Input, Step I, Step II.
2. Guess, then simulate every given line.
3. Step I alone can fit two rules.
4. Shift keeps others in order; swap does not.
5. Two-ended: odd = smallest left, even = largest right.

09Seating Arrangement

Rules

All face North: their left = West = left of your drawing. All face South: their left = East = RIGHT of your drawing.
Row of n people: k-th from the left = (n + 1 − k)-th from the right.
Strictly between box a and box b (a < b): b − a − 1 people.
Facing centre: left = clockwise, right = anticlockwise. Facing outside: left = anticlockwise, right = clockwise.
Opposite of seat k in a ring of n (n even) = seat k + n/2 (wrap around).
Rotations count as the same seating, so a ring of n has (n − 1)! patterns.
Row facing South: left = East, right = West. Row facing North: left = West, right = East.
Opposite of seat i from the west in one row = seat i from the west in the other row.
Two rows of m people give m opposite pairs.

Memorise (lesson 1)


1. Boxes first, facing line second.
2. North: left = west. South: left = east.
3. Between = b − a − 1.
4. k-th from left = (n + 1 − k)-th from right.
5. "Definitely" = true in every valid row.

Memorise (lesson 2)


1. Number seats clockwise; fix the first person.
2. Facing centre: left = clockwise.
3. Facing outside: left = anticlockwise.
4. Opposite = n/2 seats (even n only).
5. Turn everyone round: left and right swap.

Memorise (lesson 3)


1. Row 1 faces South, row 2 faces North.
2. South-facing: left = East. North-facing: left = West.
3. Opposite = same seat number from the west.
4. Two hops: opposite first, then left or right.
5. "Definitely" = true in every valid arrangement.

10Puzzles

Rules

n names in n slots can be arranged in n! (read “n factorial”: n × (n − 1) × … × 1) ways, so 5! = 5 × 4 × 3 × 2 × 1 = 120. Every clue deletes some of those 120.
A immediately above B: slot(A) = slot(B) + 1. A above B: slot(A) > slot(B).
A between B and C: slot(A) is strictly between slot(B) and slot(C). Exactly k between A and B: the slot numbers differ by k + 1.
Neighbouring: slots differ by 1. Slots strictly between p and q (p < q) = q − p − 1.
Before: slot(A) < slot(B). After: slot(A) > slot(B). Immediately after: slot(A) = slot(B) + 1.
Exactly k days (or months) between A and B: slots differ by k + 1.
Days between X and Y = |slot X − slot Y| − 1. (The bars | | mean “the gap, ignoring which is bigger”: |4 − 1| = |1 − 4| = 3.)
"A visits before B" says nothing about distance. Only words like "immediately", "next day" and "consecutive" mean 1 apart.
Table rule: each value belongs to exactly one person per category. A link puts two values in one row. A "not" crosses one cell.
Chain rule: A > B and B > C give A > C. The ">" carries through a chain.
A person is definitely the shortest only if the clues put every other person above them, directly or through a chain. A person is definitely the tallest by the mirror rule.
If both orders of two names can happen in some valid arrangement, the clues do not decide which is taller: "cannot tell".

Memorise (lesson 1)


1. Slots are numbered from the bottom; each name gets one slot.
2. Immediately above: A = B + 1. Above: A > B, any gap.
3. Between B and C is strict; either order is allowed.
4. Strictly between slots p and q: q − p − 1.
5. Anchors first, glued pairs second, "not" clues last.

Memorise (lesson 2)


1. Number the days: Mon 1 to Fri 5.
2. Before is smaller, after is bigger, immediately after is +1.
3. Exactly k between: numbers differ by k + 1.
4. Between B and C allows both orders until another clue decides.
5. Fixed day first, "not" clues last.

Memorise (lesson 3)


1. Table: direct clue fills, "not" crosses, link joins two values in one row.
2. Last value left for a person goes to that person.
3. A > B > C means A > C.
4. Do not guess what the clues leave open: test the other order.
5. Shortest = everyone else is above them (directly or by chain).

11Critical Reasoning

Rules

Implicit assumption: true in EVERY situation where the statement’s plan or claim works. (Negation test.)
Conclusion follows: true in EVERY situation where the statement is true. If it could be false, it does not follow.
Use only the statement. Outside knowledge and new facts do not count.
Conventions in this chapter: “Some” means at least one. Answer set: Only I / Only II / Both / Neither. (Some papers, e.g. IndiaBIX, add a fifth option “Either I or II”. Items in this chapter never pair two exact opposites, so that option never arises here.)
Four rival structures for “X and Y go together”: X causes Y · Y causes X · hidden Z causes both · chance.
A fact strengthens “X causes Y” if it removes rivals other than X→Y; weakens if it removes X→Y itself, or points to a specific rival (for example, shows a hidden Z driving both); is neutral if it does neither.
Convention in this guide: we count the four structures equally likely at the start (a teaching model, not a law). Then strengthen = share of X→Y rises; weaken = it falls. Removing a structure sets its weight to 0; evidence pointing to a rival raises that rival’s weight, which also lowers X→Y’s share.
If P then Q. Valid: P true ⇒ Q true. Q false ⇒ P false.
Not valid: Q true ⇒ P true; P false ⇒ Q false. (Both are Open: "Open" means the rule leaves both answers possible, so you cannot decide.)
“Only P can Q” means: if Q then P.
Course of action: assume the statement is true; pick steps that deal with the stated problem directly; reject extreme, unrelated or impossible steps.

Memorise (lesson 1)


1. Assumption = unstated idea the statement needs. Negate it: does the statement collapse?
2. Conclusion follows only if it MUST be true from the statement.
3. Too-strong words (all, always, will stop) are usually not needed.
4. “All A are B” does not reverse; “Some” means at least one.
5. No outside facts. Ever.

Memorise (lesson 2)


1. Rivals: X→Y, Y→X, hidden Z, chance.
2. Strengthen = removes rivals to X→Y.
3. Weaken = removes X→Y, or shows the gap vanishes with like-for-like.
4. Post hoc = “after” mistaken for “because”.
5. Irrelevant facts change nothing.

Memorise (lesson 3)


1. If P then Q: P guarantees Q; Q is needed for P.
2. Safe: P true ⇒ Q true; Q false ⇒ P false.
3. Traps: Q true ⇒ P? and P false ⇒ Q? are Open.
4. “Only P can Q” = if Q then P.
5. A good course tackles the stated problem and is not extreme.

12Data Sufficiency (reasoning style)

Rules

The five options used in every question here: I alone / II alone / Either alone / Both needed / Not enough. The fetched source page uses only four options; the fifth, “Either alone” (each statement by itself is enough), is our own extension so every outcome has a choice. The exact option wording and order used in PFRDA papers is unverified: read the options on the real screen every time.
Sufficient: every arrangement obeying the statement(s) gives one answer. Insufficient: two obeying arrangements disagree.
If I alone is sufficient, I and II together are sufficient too (extra true information cannot hurt).
Chain rule. Write each “A taller than B” as an arrow A → B. “X taller than Y?” is settled exactly when a chain of arrows leads from X to Y or from Y to X. “Who is tallest?” is settled exactly when one person has a chain to EVERY other person.
Link words: parent / child / sibling hide gender. Gender words: father, mother, son, daughter, brother, sister fix it.
Sibling = same two parents. A sibling’s parent is your parent.
Grandparent = parent of a parent. Uncle (this chapter) = a man who is a brother of one of your parents. Aunt = a woman who is a sister of one of your parents.
A definite “No” is sufficient. Example: “C is female” proves C is not “the son of A”.
Sum each axis separately: east-west pieces together, north-south pieces together.
Pieces on one axis all pointing the same way: the sign is fixed even if lengths are unknown.
Exactly ONE unknown-length piece on an axis: add up the known pieces. If their total points the same way as the unknown piece (or is zero), the direction is fixed. If it points the opposite way, the direction can flip, so not sufficient.
Two or more unknown-length pieces on an axis: do not trust a shortcut; test with two small examples.
Distance needs every piece known (or fixed by a statement that gives the whole chain).

Memorise (lesson 1)


1. Sufficient = every line-up that fits gives the SAME answer.
2. A definite No is sufficient.
3. Test I alone, II alone, then both.
4. Draw arrows: need a chain between the two people.
5. Tallest settled only if one person beats everyone else.

Memorise (lesson 2)


1. Answer = link + gender.
2. parent, child, sibling hide gender.
3. Full siblings share both parents.
4. One common parent does not make siblings.
5. A definite No is sufficient.

Memorise (lesson 3)


1. Statements are arrows; add east-west and north-south separately.
2. Direction needs the sign of each total.
3. Distance = √(EW² + NS²), needs all lengths.
4. Same-way arrows are safe; opposite-way unknown arrows can flip.
5. Test two small maps before saying sufficient.

13Series and Logical Misc

Rules

Gap ladder (a ratio means one term divided by the one before): (1) gaps equal → keep the gap. (2) gaps change by the same amount → keep that change. (3) gaps double (or triple) → keep that. (4) ratios equal → multiply. (5) each term = sum of previous two.
Letters: A=1 … Z=26, wrap after Z. Opposite letter of a letter: positions add to 27 (A↔Z, F↔U).
Number-letter or two-part terms: solve each part as its own series.
Odd one out: the rule must hold for ALL FOUR others and fail for exactly one.
Analogy: the rule must fit every given pair before you apply it to the question pair. If only two pairs are given, check that no second simple rule also fits.
Prime: above 1, no whole-number product except 1 times itself. 2 is prime AND even. 1 is not prime.
If P then Q is equivalent to: if not Q then not P.
Not equivalent: converse (if Q then P) and inverse (if not P then not Q).
If P then Q is false only when P is true and Q is false.
Not (P and Q) = (not P) or (not Q). Not (P or Q) = (not P) and (not Q). Not every = at least one not.

Memorise (lesson 1)


1. A=1 … Z=26, wrap after Z; opposite letters add to 27.
2. Write gaps, then gaps of gaps.
3. Flat gaps, growing gaps, doubling gaps, times a ratio, sum of two before.
4. Two-part terms: solve each part alone.
5. Stuck after 30 seconds: skip.

Memorise (lesson 2)


1. Name the rule, then test it on every item.
2. Squares, cubes, primes first.
3. Letters: write the gaps.
4. Analogy: the rule must fit pair 1 and pair 2.
5. Two rules, two answers: skip.

Memorise (lesson 3)


1. If P then Q breaks only on P true, Q false.
2. Contrapositive = flip and negate, always safe.
3. Converse and inverse: not safe.
4. Not every = at least one not.
5. Knights/knaves: test each case for contradiction.

14Safety Net: what to do when you blank

Rules

EV of a guess = p × 0.8333 − (1 − p) × 0.25
Answer if p is above about 23%. Skip if p is below it.
