## HARD RULES
1. No hallucination. Every definition/rule must come from a page you actually WebFetch (URL in the lesson Sources line) OR be a logical/mathematical fact you VERIFIED in Python (brute force/enumeration/simulation) and label 'derived, Python-checked'. Unverifiable -> omit, list as UNVERIFIED.
2. Every worked example and EVERY quiz answer must be verified by running Python from scratch: puzzles/seating by brute-force over all permutations; syllogisms by exhaustive enumeration of set models; inequalities by enumeration/numeric search; blood relations by explicit family-tree construction; directions by coordinates; coding by code; input-output by simulation. Each question must have exactly one correct option; no ambiguity (state conventions: e.g. 'Some means at least one', for syllogism).
3. Learner: ADHD, short chunks, one next action, zero background, wants full marks. Past-paper claims only as 'reported in memory-based exam analyses'. Never fabricate PFRDA question wording: label 'typical-style, written by us'.
4. Output: ONE <article class="chapter" id="chNN" data-no="NN" data-title="..." data-tag="..."> HTML fragment per chapter file chapters/NN-slug.html. Use ONLY classes and shared JS from build/shell.html ([data-steps] reveal, .quiz JSON, .drill JSON, .card .box .trap .tip .mem .oneline .bars .tw .sort .stepbox). ids prefixed chNN-. Inline <script> IIFEs only for labs. No colours except CSS variables. 375px mobile-first.
## LESSON FORMAT (all required, in order; 2-3 lessons per chapter)
1 plain-English first line (.oneline) 2 Picture this (everyday Indian scenario) 3 the idea in small steps ([data-steps]) 4 the rule only AFTER intuition (.box) 5 worked example stepped 6 the trap (.trap) 7 speed method / elimination shortcut for this topic with a drill 8 how the examiner asks (typical-style) 9 quiz >=4 Qs per lesson, answers at varied positions A-D, each wrong option explained in "t" (t array aligned with options, '' at the correct index), 10 cover-and-recall (.tip) + 'Memorise this' (.mem, <=5 lines) 11 Sources + UNVERIFIED line. Reasoning labs: interactive solvers/builders (e.g. Venn tester, arrow-walk tracker, family-tree composer, seat-grid builder) where they help.
